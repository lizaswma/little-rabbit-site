# littlerabbit.mamabuilds.dev

Table of contents for the 「小兔」(Little Rabbit) story series. Static HTML in `site/`, deployed to
GitHub Pages on push to `main`.

**Adding a book:** add its entry to the list in `site/index.html` and a cover in `site/assets/`.
Only list books once they ship.

Art and colors come from [little-rabbit-style](https://github.com/lizaswma/little-rabbit-style) and
each book's title card.
